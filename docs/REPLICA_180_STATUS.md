## 已完成的代码改造

### 1. 音频与场景流程

- 新增 \`frontend/audio/AudioManager.mjs\`：Web Audio API 播放 WAV 音效、场景 BGM，独立播放地图 MP3；按 \`sound.lst\` 的稀疏索引解析音效路径，支持 Windows 反斜杠路径、解码缓存、多音效实例和静音设置。
- 登录 BGM：\`log-in-long2.wav\`；选角 BGM：\`sellect-loop2.wav\`；死亡 BGM：\`game over2.wav\`。
- 地图音乐：\`ResourcesIndexGenerator\` 扫描可选 \`Music/*.mp3\`；\`WorldData.loadMapInfo\` 解析 \`MapInfo.txt\` 的 \`MUSIC(n)\`；地图快照包含 \`musicId\`，进图/换图时根据 \`Music/n.mp3\` 切换。
- 已接入部分原版动作声音：地表脚步、玩家挥击/部分剑术、玩家受击、怪物攻击、角色死亡、瞬移、魔法起始/飞行/爆炸、物品点击和消耗品使用。具体声音编号仍需用目标 1.80 的 \`sound.lst\` 逐项对照。
- 登录成功后播放 ChrSel[23..32] 开门动画（10 帧、300ms/帧、位置 152,96），完成淡出后进入选角。
- 选角待机/冻结/解冻动画与石化特效已按 Delphi 源码分析参数实现；角色切换触发石化解除音效。
- 选角界面删除确认和普通提示改为 WIL 素材驱动的模态消息框，不再依赖浏览器原生 \`alert/confirm\`；缺素材时有可见降级提示。

### 2. 背包、仓库与社交系统

- 登录界面的改密码流程已接通：服务端验证当前密码，生成新随机 salt/hash，更新 SQL 同时校验旧哈希和 salt；前端校验长度、重复输入和不能与旧密码相同。
- 新增仓库面板：查看仓库物品、存入背包物品、取出仓库物品；服务端每次存取后同步仓库/背包状态，背包达到 46 格时拒绝取出。
- 交易：发起/接受/拒绝请求，双端显示报价物品、金币和确认状态；限制同地图 10 格内；修改报价会清除双方确认；成交前检查背包空间；取消、拒绝、超时或断线时返还托管物品和金币。
- 组队：邀请接受/拒绝后才真正加入；成员状态包含等级、HP、地图和坐标；队伍聊天、移动/换图/PvP 后状态同步；断线时自动移出队伍。
- 行会：创建/加入/退出、成员/长老/同盟/敌对列表、宣战/结盟、行会聊天；成员变动向在线成员广播状态。
- 交易与组队邀请 5 分钟过期；双方断线/超时会收到状态关闭通知。

### 3. 沙巴克攻城与地图门

- 新增 \`CastleStateStore\`，将可变城堡状态原子写入 \`Mir200/Envir/Castle/Sabuk.runtime.properties\`，不覆盖原始 \`Sabuk.txt\`。
- 持久化城主行会、城门 HP/开启状态、三段城墙 HP、攻城行会和结束时间；服务端启动时恢复并同步行会城主标记。
- 已接通城门和左/中/右三段城墙攻击，验证攻击行会、地图、距离及目标状态；广播城堡状态到客户端。
- 客户端处理 \`doorState\`，根据原版 \`FrontDoorOffset\` 开门偏移切换对象图像。
- 进图/换图快照携带当前已打开门坐标，新玩家进入同一地图也能恢复现有开门状态。

### 4. 资源加载、性能与启动诊断

- WIL RangeScheduler 使用稳定优先级队列；当前实体动画帧高优先级，可视地图资源次之，常用动作预取再次之；活动/排队请求仅在现有区间完整覆盖时去重。
- 新实体预取站立/行走常用帧；实际渲染帧保持更高优先级。
- 地图并发加载去重，失败后从缓存清除并允许重试；WIX 索引失败后也允许重试。
- 实体移除、换图和退出时释放精灵/特效引用，避免持续刷怪和换图积累缓存。
- 服务端资源索引要求 Data/Map；Wav/Music 可选，便于无音频资源时做画面调试。
- 必需图像库或地图缺失时，客户端会展示明确启动诊断，不以假素材冒充原版。

## 资源目录约定

资源根目录预期结构：

- \`Data/\`：原版 WIL/WIX 图像库
- \`Map/\`：原版 \`.map\` 地图
- \`Wav/\`：WAV 和 \`sound.lst\`
- \`Music/\`：地图 MP3，按 \`MapInfo.txt\` 的 \`MUSIC(n)\` 匹配 \`n.mp3\`

仅使用有权使用的客户端资源。导入前检查来源、许可证和文件安全；不要运行来源不明压缩包中的程序。
