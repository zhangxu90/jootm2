## 已提交的实质改造

1. **浏览器音频引擎**（\`frontend/audio/AudioManager.mjs\`）
   - 使用 Web Audio API 播放 WAV 音效和循环场景音乐。
   - 解析原版 \`Wav/sound.lst\` 稀疏数字索引，支持 Windows 路径。
   - 区分 WAV 场景 BGM、一次性音效和地图 MP3 通道。
   - 首次鼠标/键盘交互后解锁浏览器音频；缺少资源时静默降级，不阻塞游戏。
2. **场景 BGM**
   - 登录场景：\`log-in-long2.wav\`。
   - 选角场景：\`sellect-loop2.wav\`。
   - 游戏 HUD 声音开关已连接到音效管理器。
3. **地图音乐**
   - \`ResourcesIndexGenerator\` 可选扫描 \`Music/*.mp3\`。
   - \`WorldData.loadMapInfo\` 解析原版 \`MapInfo.txt\` 的 \`MUSIC(n)\` 标记。
   - 地图快照携带 \`musicId\`；进入/切换地图时按 \`Music/n.mp3\` 播放，使用独立 MP3 通道。
4. **部分原版动作声音**
   - 本地角色走/跑按地图地表触发左右脚声音。
   - 玩家武器类别对应挥击声及部分剑术声音。
   - 玩家受击、怪物攻击、角色死亡和瞬移声音。
   - 背包物品点击和消耗品使用声音。
5. **改密码闭环**
   - 登录界面原有修改密码窗口已接通。
   - 服务端必须核对当前密码，更新随机 salt 和密码哈希。
   - SQL 更新同时校验旧哈希和 salt，防止并发修改覆盖。
   - 前端校验新密码长度、两次输入一致及不能与旧密码相同。
6. **自动化验证**
   - GitHub Actions 检查前端所有 \`.mjs\` 语法、运行音效索引单元测试并执行 Maven 验证。
   - 新增 \`WorldDataMapInfoTest\` 和 \`AccountPasswordChangeTest\`，覆盖地图音乐标记解析和密码修改流程。
   - 第一轮 CI 已通过前端语法、模块导入、Java 打包及补丁检查；新增 JUnit 测试后的结果以 GitHub Actions 最新运行记录为准。

## 资源目录约定

服务端资源根目录应包含：

- \`Data/\`：原版 WIL/WIX 图像库
- \`Map/\`：原版地图文件
- \`Wav/\`：WAV 文件及 \`sound.lst\`
- \`Music/\`：地图 MP3；按 \`MapInfo.txt\` 的 \`MUSIC(n)\` 标记匹配 \`n.mp3\`

仅使用有权使用的客户端资源。不要从来源不明的压缩包执行程序；对素材包先进行安全扫描和许可证核查。
